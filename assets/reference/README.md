# 角色参考

Rin 的角色外观以 [《Shelter》官网](https://www.sheltertheanimation.com/)及其[官方角色图](https://www.sheltertheanimation.com/resources/img/pct_rin.png)为参考。

本机用于制作对照的官网原图不纳入源码仓库和发布包。运行与构建只需要 `assets/rin`、`assets/world`、`manifest.json` 和 `catalog.json`，无需下载官方参考图。

素材制作过程与实际提示词见 [素材制作](../../docs/素材制作.md)。

父亲与幼年Rin同时对照官网角色图及[官方影片](https://www.youtube.com/watch?v=fzQ6gRAEoy0)：约3:46秋千、4:06整理发饰。原始参考图不随包分发，使用新生成插画。
