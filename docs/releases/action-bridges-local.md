# 动作起止与山径回程修订（2026-10-23～24，本地未发行）

本轮为38组动作补齐从站立进入、结束后回站的过程。普通动作使用三张新制作的完整人物图集，包含贴地起落、坐下/起身和上身中间姿态；连续变形只连接相邻实际关键画面。小跑、轻跃、转身、草地、秋千、平板和户外原有专用过程保留，最终接回原基础站姿。

登山普通结束不再从山顶直接回到山脚。点击Rin、“结束观景”、新动作或创造/消息请求会沿有效山径实际下山，抵达并站稳后再执行最后请求；上山中完成当前上行路线再返回，下山中保持进度。进入上/下山各约0.48秒换重，山顶/山脚各约0.56秒收脚回正。拖动、场景/模式改变、整理与山径失效继续立即让位。

本地程序为`dist/local/action-bridges/RinsLittleShelter`，便携及源码素材附件位于同级`release`。程序元数据仍为1.0.2；当前路径与本说明用于区分本地修订和已经公开的v1.0.2旧附件。此前`climb-continuity`、`motion-exit`及更早程序/包/记录全部保留，本轮不自行新建Tag或上传GitHub。

须完整解压并配套使用EXE、manifest、`bridge-ground-v1.png`、`bridge-seat-v1.png`、`bridge-upper-v1.png`、`action-bridge-art.json`、`pose-bridges.json`及既有运行素材。单独复制新EXE或只替换某一张PNG可能造成缺失或登记不匹配。

最终复核还修正了转身时把手臂误判为脸的配准错误、坐下末帧的座面位移、点触平板直接跳到收板及记忆淡出中止时的身体交接。山顶转身完成收脚站稳后才开始下山，避免交叉腿直接变成登山腿。实际程序绘图的起落、持板和山径往返预览随包交付于`docs/screenshots`。

保持安静陪伴、单一Behavior时钟、透明命中、用户中断和版本1存档；成长、故事、来信、创造次数及两模式/各场景布局不变。设计与素材限制见[动作起止过渡](../动作起止过渡.md)，逐项核对见[38组检查表](../动作过渡检查表.md)。实际检查和仍待验收范围以[验证记录](../验证记录.md)为准，本说明不预写新图集通过数，不把路线检查、离屏绘图或短运行写成原生Windows或一小时稳定性通过。
