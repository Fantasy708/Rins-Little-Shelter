# 山径连续迈步修订（2026-10-23，本地未发行）

本轮针对登山中的头身比例变化和每步停走感，采用登山专用的连续双腿蒙皮：同一人物贴图保持脸、上身、短裤和头发一致，近远腿轮流在石阶支撑、抬起并迈步。身体与双脚使用同一个Journey时间相位；登顶、回到山脚各增加约0.32秒收脚站稳，再接看天或日常站姿。

新生成的多帧候选没有可靠画出交替步态，因此没有作为“32帧原画”交付。运行只使用`climb-body-v2.png`中的一个完整人物裁切与`climb-registration.json`；16个诊断相位不代表16张原画。旧登山图集保留为历史而不再播放，其他动作的既有素材与收尾继续使用。

本地程序目录为`dist/local/climb-continuity/RinsLittleShelter`，便携和完整源码素材包放在同级`release`。须完整解压，EXE、manifest、新PNG与登记JSON配套使用。保持1.0.2基线元数据，本次没有新建GitHub标签或上传；已公开版本及此前各本地包保留。

沿用原山脉、八个路线点、成长进度、故事状态和两模式独立布局。单一Behavior调度、用户中断、透明区域命中、窗口规则与存档版本1不变。髋膝踝连接、鞋边、指定支撑脚接地及看天/站姿比例交接需要按本轮程序检查；实现与素材限制见`docs/登山动作修复.md`，**实际完成与结果见`docs/验证记录.md`**。本说明不宣称短运行、一小时稳定性或人工桌面验收通过。
