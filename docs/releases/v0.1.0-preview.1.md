# Rin’s Little Shelter v0.1.0-preview.1

首个Windows预览版：Rin 安静地在桌面角落生活，通过平板创造自己的小世界。

## 下载与启动

下载 `RinsLittleShelter-v0.1.0-preview.1-win-x64.zip`，完整解压后运行 `RinsLittleShelter.exe`。支持Windows 10（19041及以上）/11 x64，已包含.NET运行环境，无需安装SDK。保留旁边的 `assets` 文件夹。

初次打开是Rin与云台。右键Rin选择“进入自由创造”可立即体验完整世界；成长模式与自由模式分别保存布局。

源码与素材另附 `RinsLittleShelter-v0.1.0-preview.1-source.zip`。校验文件为 `SHA256.txt`。

## 内容

- 29组动作与12个景物，支持成长、自由创造及整理布局。
- 本地时间天空、晴雨风雪、系统声音联动与手动理想世界入口。
- 透明窗口、托盘、拖动、暂停、隐藏及完全鼠标穿透。
- 修正整腿晃动、独立小跑、减速回椅、坐姿接触位置、轻跃/转身节奏，以及透明叠帧引起的闪烁与双影。
- 默认静音、休息提醒和登录启动关闭；音频只在内存中分析。

## 测试范围

57项核心检查、生产WPF画面与姿势过渡检查、3次真实默认音频设备启停通过；当前EXE完成60.4秒独立存档短运行。当前版本尚未重测一小时，部分系统交互、多屏和音频设备变化仍待实测，详见源码中的 `docs/发布状态.md`。
