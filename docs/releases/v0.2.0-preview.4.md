# Rin’s Little Shelter v0.2.0-preview.4

Windows多场景预览版：Rin从云台走进房间、院子和草坡，最终拥有树下秋千；卧室改为明亮、干净的动画画风。

2026-10-15文档补充：本页保留preview.4当时的功能与验证范围；仓库现已公开。更早的preview.1～3已用原包补发，全部入口见[发行索引](../发布状态.md#发行索引2026-10-15)。当前建议使用v0.3.1-preview.2，本次不替换preview.4的标签或附件。

## 下载与升级

下载 `RinsLittleShelter-v0.2.0-preview.4-win-x64.zip`，完整解压后运行 `RinsLittleShelter.exe`。支持Windows 10（19041及以上）/11 x64，已包含.NET运行环境，无需安装SDK。保留旁边的 `assets` 文件夹。

升级前退出旧版。新版继续读取本机原有存档，保留陪伴进度、两种模式的独立布置和用户自定义位置/隐藏状态。旧版已访问的院子保留访问权；不把既有成长进度清零。

源码与全部运行素材另附 `RinsLittleShelter-v0.2.0-preview.4-source.zip`，校验清单为 `SHA256.txt`。[发行附件](https://github.com/Fantasy708/Rins-Little-Shelter/releases/tag/v0.2.0-preview.4)现可公开下载；私有访问要求属于发布时状态。

## 相比首个发布版

- 五阶段场景按累计陪伴日开放：初始云台、第2日屋内、第7日院子、第10日室外草坡、第20日树下秋千；自由模式全部开放。每模式、每场景分别保存布置，解锁不强制切换。
- 秋千包含走近、扶绳、坐下、轻荡、停稳、起身与离开；专用完整姿势与实际步行，手、绳、身体和座板共享锚点。
- 树下与屋内均有用户主动触发的父女记忆，支持重看和随时结束。记忆默认静音，临时陈设不覆盖保存的布置，结束后秋千仍保留。
- 日常卧室保留原片现在的Rin房间陈设，使用暖玫瑰墙面、浅灰地砖、奶油窗帘、粉色床品、淡绿柜子和柔和日光；去掉裂墙、污旧纹理及厚重深褐阴影。
- 窗内天空随昼夜主题变化，雨雪风限制在玻璃后；屋内休息使用可见床铺，取消地板躺卧、无座晃腿及不适合室内的户外动作。修正床沿接触、家具前地面落点与窗边朝向。
- 保留原有动作、音乐联动、整理世界、透明窗口和托盘功能，共34组动作、20种景物定义。默认静音，休息提醒和登录启动关闭。

## 已验证与仍待实测

57项核心、165项场景逻辑、671项实际生产WPF绘图检查通过，另重跑完整动作、接触和不透明度回归。绘图覆盖100%/150%/200% DPI、秋千绳手对应、床沿坐姿、五种天空、窗外天气、记忆结束与取消恢复。3次真实默认音频设备启停通过，本次系统静音。

最终EXE与素材组合从新解压目录使用独立版本1存档运行60.6秒、2,732实际绘制帧，正常退出，无诊断日志，进度、各场景布置及备份保持一致。
