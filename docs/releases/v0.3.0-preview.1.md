# Rin’s Little Shelter v0.3.0-preview.1

平板界面历史预览版：Rin先展示平板，用户在屏幕内选择并确认创造，也能主动打开消息页阅读父亲来信。

本版发布时仓库为私有，后续已公开，[发行附件](https://github.com/Fantasy708/Rins-Little-Shelter/releases/tag/v0.3.0-preview.1)现可直接下载。2026-10-15补充说明：下文三页摘要和验证数据均属当时版本，当前v0.3.1-preview.2已使用九页中文译文。全部版本见[发行索引](../发布状态.md#发行索引2026-10-15)，本次不移动原标签或替换附件。

## 使用与升级

本地附件为 `RinsLittleShelter-v0.3.0-preview.1-win-x64.zip`、`RinsLittleShelter-v0.3.0-preview.1-source.zip` 与 `SHA256.txt`。完整解压便携包后运行 `RinsLittleShelter.exe`，保留旁边的 `assets`。支持Windows 10（19041及以上）/11 x64，自包含.NET运行环境，无需SDK。

升级前退出旧版。沿用本机版本1存档，保留陪伴日、成长进度、两种模式及各场景独立布置；新增故事记录安全补全。平板会话不保存，重启恢复日常。

## 本次更新

- 创造入口统一到平板：右键、托盘、图鉴均先展示、展开、选择、预览与确认，再收回、点触、生成、观察和收起。专用完整姿势与手部/屏幕锚点保持衔接，正常人物不淡化闪烁；必要让位使用实际步行。
- 候选遵守当前场景/模式门槛，每页最多四项。隐藏物件恢复保存位置，已显示景物不复制；确认只接受一次，景物在点触动作58%节点产生。预览和消息不改布置。
- Rin自主创造保留。主动邀请每日最多三次，平板可操作后20秒未回应收起；实际点选或切页转手动会话。手动打开和阅读不消耗主动邀请。
- 平板内“创造 / 消息”两页共享开合，成长初始显示固定“No messages in 2593 days.”，2593与实际陪伴日无关。
- 第20陪伴日开放父女记忆；完整看过屋内或树下任一片段、现在的Rin淡入恢复后开放同一封信。提前退出不算，重复观看不重复生成。自由模式立即可读，两模式分别保存故事与已读状态。
- 来信只有平板内稳定未读标记，不自动打开、不弹窗、不发声音。主动正文实际呈现后标记已读，可随时重读；14逻辑像素中文摘要手动三页，标注“原作来信内容摘要”，不署作父亲原话，不增加回复/发送。
- 拖动、整理、切换、记忆、隐藏、暂停、锁屏、全屏隐藏和完全穿透关闭平板并清除过期命中，恢复不自动重开。屏幕外透明空白继续允许操作下面的窗口，不抢键盘焦点。

两份平板设计、完整源代码、角色和场景素材、构建脚本及中文说明一同交付。素材提示词见 `docs/多场景素材制作.md`，参考核对与实际检查范围见相关文档。

## 验证与限制

434项平板/故事逻辑、1325项生产WPF平板绘图、250项生产窗口接口集成及既有57项核心、165项场景/记忆、671项场景绘图和34组动作回归通过。默认输出设备3次真实静音WASAPI启停通过。新解压包用独立旧存档消息页60.9秒/2771帧、重启创造页60.8秒/2697帧，正常退出、无异常，布局与成长保持；这些是短运行与自动检查，不是人工桌面验收。

**尚未完成本版本的一小时稳定性测试。** 自动逻辑、WPF绘图和短运行不等同于真实桌面拖动、穿透、全屏/锁屏、多屏及Windows缩放切换。

本项目为《Shelter》同人桌面作品，未附带原曲、原片帧或原片音轨。角色与第三方组件来源见 `CREDITS.md` 和 `THIRD-PARTY-NOTICES.md`。
