# Rin’s Little Shelter v0.3.0-preview.2

草地与Nurture手动彩蛋预览版。沿用当前公开仓库发布，已有预览版、标签和附件保持原样。

## 更新

- 以官方Nurture标准封面重绘连续自然草甸，细草和白黄小花遍布中央与边缘，取消花环和黄色空心区，院子草地适度统一。使用原alpha遮罩，尺寸、透明轮廓、行走落点与保存布置不变；其他场景资源保留。
- 新增“Nurture·拥抱草地”右键及动作页入口。实际走近、站稳、收平板，再通过20个专用完整姿势下降、俯卧停留4.5秒、撑起和起身，随后走回日常位置。背向俯卧，头固定右上、脚左下、双臂展开，左向进入先真实转身，不强行露正脸，身体常态不透明；默认静音，不自动音乐或通知。
- 可见、已解锁且有足够空位的草地才允许播放，现有浅院子因远侧掌部超出草地而禁用。家具/小路挡住、空间不足或草地隐藏时禁用，不搬动布置。云台、卧室、家具坐姿和秋千活动禁用，随机日常不包含本动作。
- 拖动、创造、记忆、整理和场景/模式切换取消；暂停、隐藏和全屏按现有规则冻结。兼容版本1存档，成长及两模式独立布置保留。

## 使用

完整解压 `RinsLittleShelter-v0.3.0-preview.2-win-x64.zip`，保持EXE与assets相邻。升级先退出旧版，继续读取本机原存档。进入室外草坡，在右键或动作页选择彩蛋；现有院子草地深度不足以容纳斜向双臂，本版该入口禁用，不强缩人物或挪动布置。

源码素材包、SHA256、中文说明、设计基准和Nurture素材制作文档一同交付，预览来自实际生产绘图。没有附带官方封面原图、原曲或音轨。

## 验证范围

已完成389项逻辑和1168项生产绘图/接触/轮廓/不透明度/三档导出缩放/窗口接口检查；既有回归与最终便携短运行以验证记录为准。自动绘图不是原生Windows输入验收。

本版本尚未进行一小时稳定性。真实桌面操作、混合多屏/系统缩放、隐藏及全屏往返的主观观感仍待人工实测，不将短运行或旧版本时长算作通过。完整结果见docs/验证记录.md及docs/发布状态.md。
