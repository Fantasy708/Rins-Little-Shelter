# Rin’s Little Shelter v0.3.1-preview.1

启动开场预览版：星光、天空和草甸逐渐出现，Rin苏醒、观察、拿起平板，让一粒种子开花，再回到当前保存的场景。按用户最新要求采用预览版号，沿用现有main创建新标签，保持公开仓库和旧发行、标签及附件。

## 更新

- 首次完整开场约14.4秒，后续简版约3.1秒；设置可选择每次完整或直接进入桌面，支持随时跳过及手动重看。
- 复用现有Rin、草甸、云、花和专用持板姿势，保持半Q版插画风格。默认静音、不覆盖整屏、不抢焦点，以微笑回应交接日常。
- 临时开场景物不提前解锁，不修改成长或两模式/各场景布置，不消耗创造次数或生成来信。
- 隐藏、暂停、锁屏、全屏、整理、场景/模式切换等操作优先结束，清除旧命中，恢复不自动重播。随后继续原有日常与音频设置。
- 兼容版本1存档，安全补全全局已看记录和播放设置；保留Nurture彩蛋、平板消息、父女记忆与保存布局。

## 使用

完整解压`RinsLittleShelter-v0.3.1-preview.1-win-x64.zip`，保持EXE与`assets`相邻。升级前退出旧版，新版继续读取本机原存档。画面右下角及托盘有“跳过开场”，设置页提供三种“启动开场”策略和“重看开场”。

附件为Windows x64自包含便携包、完整源码素材包和SHA256，随附中文说明、设计基准与开场设计。不包含原曲、原片音轨、官方参考照片、个人存档或工具链。
