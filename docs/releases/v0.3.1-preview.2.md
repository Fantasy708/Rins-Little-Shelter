# Rin’s Little Shelter v0.3.1-preview.2 · 首个公开内测版

本轮首个公开内测版，计划于2026-10-15 20:00起面向朋友圈邀请用户测试。此名称表示本轮开始邀请内测的阶段；已有GitHub公开历史预览继续保留。新版将旧三页来信摘要替换为九页中文译文，并新增统一应用图标；沿用原main创建新Tag，保留v0.3.1-preview.1及所有旧发行、标签和附件。

## 更新

- 正文显示“来自：爸爸 · 中文译文”，使用父亲第一人称，保留`(^_^)`，以14逻辑像素分九页手动阅读，不自动滚动。
- 依据2026-10-15用户提供的日文转写翻译，本轮没有重新逐帧核对原片。结尾止于“再把那天的话，对你说一次。”，不添加用户未提供的结语或剧情。
- 解锁、未读、已读、重读及两种模式隔离保持。成长模式仍需第20日完整观看任一父女记忆；自由模式直接开放。换正文不重置旧已读记录，不修改布置、成长或创造次数。
- 启动开场、五场景、平板创造、父女记忆与Nurture彩蛋沿用现有实现，默认静音，不新增通知或通信功能。
- 新增Rin、平板与小花主题的统一应用图标，用于EXE、托盘和设置窗口，保持项目现有插画风格；PNG原稿与七尺寸ICO位于`assets/app`。

## 使用

完整解压`RinsLittleShelter-v0.3.1-preview.2-win-x64.zip`，保持EXE与`assets`相邻。升级前退出旧版，新版继续读取本机原有版本1存档。从右键或托盘打开“查看平板消息”，主动点开来信后手动翻页；已经读过的信仍可重读。

发行附件包括Windows x64自包含便携包、完整源码素材包和SHA256。中文说明、平板设计及参考边界随包交付，不包含原曲、原片音轨、个人存档或本机工具链。
