# Rin’s Little Shelter v0.3.1

为小世界增加安静的启动开场：星光、天空和草甸逐渐出现，Rin苏醒、观察、拿起平板，让一粒种子开花，再回到当前保存的场景。沿用现有公开仓库发布，旧发行、标签及附件保留。

## 更新

- 默认首次完整开场约14.4秒，后续简版约3.1秒；设置可选择每次完整或直接进入桌面，支持随时跳过及手动重看。
- 复用现有Rin、草甸、云、花和专用持板姿势，与既有插画风格保持一致。默认静音、不覆盖整屏、不抢焦点；首版以微笑回应交接日常。
- 开场只呈现临时景物，不提前解锁、不修改成长与两模式/各场景布置，不消耗创造次数或生成来信。
- 隐藏、暂停、锁屏、全屏、整理、场景/模式切换等操作优先结束，清理旧命中，恢复不自动重播。交接后继续原有日常和音频设置。
- 兼容版本1旧存档，新增全局已看记录与播放设置；Nurture彩蛋、平板消息、父女记忆和原有布局保留。

## 使用

完整解压`RinsLittleShelter-v0.3.1-win-x64.zip`，保持EXE和`assets`相邻。升级前退出旧版，新版继续使用本机原有存档。点击开场右下角或托盘的“跳过开场”即可直接进入；设置页提供“启动开场”选项与“重看开场”。

发行附件包括Windows x64自包含便携包、完整源码素材包及SHA256。中文使用说明、设计基准和开场设计一同交付，不包含原曲、原片音轨、官方参考照片、个人存档或本机工具链。
