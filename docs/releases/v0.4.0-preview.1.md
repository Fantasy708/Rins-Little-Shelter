# v0.4.0-preview.1 · 户外探索公测预览版

本地预览交付，尚未上传GitHub。项目持续开发，本版不是最终版；旧发行、标签与附件保留。

新增山脉与极地两个480×340桌面场景：第12个累计陪伴日开放赭红砂岩台地，第16日开放蓝色雪景与绿黄极光，自由模式立即开放。第20日秋千、父女记忆和来信规则不变，旧存档的成长、已读与两模式各场景布置继续保留。

新增“登上山顶”“仰望极光”“伸手接雪”。登山使用24张专用上/下山完整姿势，沿石阶登顶、停留、转身并下山；接雪使用12张专用抬掌与收手姿势。角色仍由单一状态机调度，拖动、平板、创造、记忆、整理和场景/模式切换优先。默认静音，不自动播放音乐或增加通知。

场景依据用户提供的原片截图重新绘制，保留赭红砂岩颜色与峰形、青蓝冰柱、蓝色积雪和绿黄极光，不附带原片截图或音轨。完整提示词、资源摘要和锚点见`docs/户外探索素材制作.md`。

本版交付Windows x64自包含便携ZIP、完整源码素材ZIP和SHA256清单。解压后运行`RinsLittleShelter.exe`，保留同目录`assets`；无须安装开发工具。右键“前往场景”切换，右键或设置动作页体验专属动作。成长条件未到时可切入自由模式预览，不会提前改变成长模式。

实际检查范围、短运行数据与待人工项目见`docs/验证记录.md`，简明状态见`docs/发布状态.md`。生产绘图及100%/150%/200%绘图缩放不代替原生Windows键鼠、真实系统缩放、多屏与一小时稳定性验收。旧版时长与哈希不计入本版。
