# v1.0.0 · 首个正式版

这里有一个正在成长的小世界。

Rin's Little Shelter 首个正式版，以《Shelter》十周年为纪念主题。按维护者最新安排于2026年10月16日提前提供，替代原定10月18日12:00的首发时间；项目会继续更新。

## 本版内容

- 云台、卧室、院子、草坡、赭红山脉、极地极光、树下秋千共七个场景，成长与自由模式分别保存布置。
- 平板内选择、预览和确认创造，白色碎粒在景物位置汇成形状，再过渡到实体。
- 父女记忆、父亲来信九页中文译文、Nurture拥抱草地、山径登顶、接雪与Shelter创造回顾。
- 修复窗口强制置顶：默认关闭“始终置顶”，设置修改立即生效并持久保存；旧档默认关闭，真正全屏仍自动隐藏。
- 正式版程序元数据、设置页、构建目录和中文说明同步为v1.0.0；沿用最新README、许可证与署名。后续继续修复与完善。

## 下载和升级

下载`RinsLittleShelter-v1.0.0-win-x64.zip`，按`SHA256.txt`校验，完整解压后运行EXE，保留旁边的assets目录。支持Windows 10（19041及以上）/Windows 11 x64，自包含.NET运行环境。升级前退出旧程序；默认沿用原存档，成长、两模式布局及来信状态保留。

`RinsLittleShelter-v1.0.0-source.zip`包含完整源码、运行素材、设计文档、中文说明、测试和构建脚本。旧版本、标签和附件保留。程序不附歌曲或原片音轨，默认静音，不自动播放音乐。
