# v1.0.1 · 秋千动画修复

这次小更新修复Rin日常荡秋千与树下父女记忆中的顿挫，并调整扶绳、坐下和起身时的人物比例与衔接。继续保持安静陪伴的节奏，没有新增通知或自动音乐。

## 修复内容

- 日常和记忆中的摆荡使用专用完整姿势，腿部、发梢与父亲的扶推动作随时间连续变化，减少稀疏姿势切换造成的跳动，保持人物不透明，避免重影。
- 身体按统一比例登记，仅在手臂附近对齐绳索，修复上秋千时整个人突然被拉宽的问题。起坐保留实际屈膝姿势，臀部与座板、脚部与地面分别对齐。
- 修正停稳、起身时进入记忆、记忆淡入淡出及记忆结束后空秋千的衔接，减少姿势、位置和摆角突变。
- 保留阶段间的时间余量，使30/60Hz时间步下的动作节奏一致；重复绘制复用固定缓存。

## 下载与升级

下载本发行的`RinsLittleShelter-v1.0.1-win-x64.zip`，使用同页`SHA256.txt`核对文件。先正常退出旧程序，再将新版完整解压到独立目录，运行`RinsLittleShelter.exe`；EXE与旁边的`assets`文件夹须保持在一起。

支持Windows 10（19041及以上）和Windows 11 x64，自带.NET运行环境，无须安装开发工具。默认沿用原存档，不重置陪伴进度、成长/自由模式各场景布置或来信状态；本次不增加存档字段。升级前可按[使用说明](https://github.com/Fantasy708/Rins-Little-Shelter/blob/v1.0.1/README.md)备份存档。

`RinsLittleShelter-v1.0.1-source.zip`提供完整源码、运行素材、设计文档、中文说明、测试和构建脚本。旧版本、标签和发行附件继续保留。
