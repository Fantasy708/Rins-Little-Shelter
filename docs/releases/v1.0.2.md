# v1.0.2 · 白色创造过渡更新

Rin在平板中确认创造后，细碎光粒会在景物位置聚集，连成完整的白色形体，再从不同区域逐渐显出颜色。Rin自主创造也使用相同效果。这次更新对照《Shelter》原片的白色光片与形体生长，适配桌面小世界的大小，保持安静、轻盈的节奏。

## 更新内容

- 白色碎粒更细，流入有先后；连续白形保留树冠、树干、花茎及素材内部透明空隙，减少稀疏点阵感。
- 白形在原位逐区域显色，保持完整尺寸；生成前后采用同一图层与昼夜照明，修正深夜切换时的亮度变化。
- 缓存与粒子数量有界，帧间复用，不增加依赖、音效、通知或设置。拖动、暂停、隐藏、场景/模式切换等中断规则保留。
- 原58%真实创建节点、创造次数、保存位置、成长进度、两模式布局及来信状态不变。保留v1.0.1的秋千动画修复；歌曲回顾与开场仍沿用各自效果。

## 下载与升级

下载本发行的`RinsLittleShelter-v1.0.2-win-x64.zip`，使用同页`SHA256.txt`核对。正常退出旧程序，将新版完整解压到独立目录，运行`RinsLittleShelter.exe`，让EXE与旁边的`assets`文件夹保持在一起。

支持Windows 10（19041及以上）和Windows 11 x64，自带.NET运行环境。沿用原存档，无须重置进度；升级前可按[使用说明](https://github.com/Fantasy708/Rins-Little-Shelter/blob/v1.0.2/README.md)备份。

`RinsLittleShelter-v1.0.2-source.zip`提供完整源码、运行素材、测试、构建脚本、设计文档和中文说明。旧版本、Tag及发行附件继续保留。

## 验证与边界

本版完整构建通过，包含74898项数值检查及通用角色绘图。创造检查覆盖真实手动/自主生成、重复确认、取消与中断、透明命中、原存档兼容、三档离屏DPI，以及完整白形、内部孔洞、局部显色、昼夜节点与缓存边界；窗口、场景、平板、记忆、回顾和音频回环启停一并通过。本轮未播放歌曲，不能据此宣称真实播放器识别通过。
