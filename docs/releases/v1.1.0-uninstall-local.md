# v1.1.0 便携包与Setup的一键卸载更新

2026-10-25。应用仍为已发布的v1.1.0，只更新脚本与交付文件，不重新编译EXE、不改变素材、存档或陪伴行为。用户已授权更新同一GitHub发行；打包时为发布准备，完成后的服务器核对单独记录。六个旧附件改名归档，原本地包与原应用Tag保留。

- 完整便携包增加`Uninstall-RinsLittleShelter.cmd`，双击可卸载当前这份程序；移动或改名后的目录仍适用。
- Setup脚本包同时带安装和卸载入口，安装后也保留卸载脚本，支持原便携包和带相对清单的新便携包。
- 卸载前请从托盘正常退出Rin。卸载不强杀进程，不联网、不需管理员权限。
- 陪伴进度、场景布置、消息和设置保留在`%LOCALAPPDATA%/RinsLittleShelter`；用户添加/修改的文件与空目录保留。
- 必须完整解压并保留支持脚本和登记文件，不能只把CMD复制到没有登记的旧便携文件夹使用。

交付目录：`dist/local/v1.1.0-uninstall/release`。便携、源码和Setup分别使用同目录新校验清单；旧发行SHA256不适用于此次重新整理的ZIP。

完整源码包包含此次脚本和文档维护，以GitHub发行正文注明的冻结源码提交为准；原v1.1.0应用Tag继续指向首次发布的程序源码，不移动它来覆盖历史。归档旧文件名含`before-uninstall-20261025`，仅供回退；日常下载没有该后缀的正式文件。新Install PS1需与两份Uninstall支持文件配套，推荐完整Setup ZIP。
