# v1.1.0 · 动作与记忆更新

这次把近期的动作与记忆修订统一整理为正式版本。Rin从站立进入日常动作，结束后收手、起身或收脚，再接回下一项；走向山顶与沿山径返回也有完整过程。屋内父女记忆留在熟悉的粉色卧室，保留你布置的小世界。

## 更新内容

- **动作有始有终。** 按38组动作补齐开始与回站过程，增加贴地起落、坐下/起身和上身中间姿态。小跑、轻跃和转身使用专用减速、着地与回正收尾，保持人物比例和落脚一致。
- **完整走过山径。** 登山双腿连续交替支撑与迈步，登顶和回到山脚先收脚站稳。普通点击、“结束观景”、新动作或平板请求先沿有效路线返回，再执行最后一次请求；拖动与切换场景仍立即响应。
- **接住当前动作。** 平板、拖动、秋千、草地、记忆、开场和歌曲回顾从当前实际画面接续。趴卧或秋千时选择新动作先起身或离座，连续请求保留最后一项；暂停或隐藏后不会补开尚未展开的平板。
- **记忆与日常共用卧室。** 屋内父女片段沿用粉色墙面、高窗、床、圆几和柜子，保留家具位置、隐藏状态与窗外昼夜天气，以柔和暖光区分回忆氛围。
- **继续保留原来的生活。** 七场景、连续白色创造、秋千修复、成长进度、两模式独立布置、记忆完成与来信状态继续保留，没有新增存档字段或声音、提醒、设置。

## 下载与升级

下载本发行的`RinsLittleShelter-v1.1.0-win-x64.zip`，使用同页`SHA256.txt`核对。正常退出旧程序，将新版完整解压到独立目录，运行`RinsLittleShelter.exe`；EXE、`assets`中的图集、登记JSON与manifest须配套使用。

支持Windows 10（19041及以上）和Windows 11 x64，自带.NET运行环境。兼容既有存档，无须重置进度；升级前可按[使用说明](https://github.com/Fantasy708/Rins-Little-Shelter/blob/v1.1.0/README.md)备份。

`RinsLittleShelter-v1.1.0-source.zip`提供完整源码、运行素材、测试、构建脚本、设计文档及中文说明。旧版本、Tag与发行附件继续保留，近期各轮独立本地包及验证记录也保留为开发历史。

## 验证与边界

近期修订已有针对动作起止、人物比例、指定支撑脚、完整山径、平板、记忆、真实透明命中与旧存档的逻辑及生产绘图检查。本版重新构建EXE，其元数据、独立短运行、存档与附件核验另行记录；具体结果和覆盖范围见[验证记录](https://github.com/Fantasy708/Rins-Little-Shelter/blob/v1.1.0/docs/%E9%AA%8C%E8%AF%81%E8%AE%B0%E5%BD%95.md)，发布核验见[发布状态](https://github.com/Fantasy708/Rins-Little-Shelter/blob/main/docs/%E5%8F%91%E5%B8%83%E7%8A%B6%E6%80%81.md)。旧程序的哈希与运行时长不代替本版结果。

画面由二维完整插画、专用姿态与相邻姿态变形实现，仍有源插画视角和遮挡的限制。逻辑覆盖38组动作不等于全部动作排列均经人工观看；离屏缩放、模拟生命周期和短运行也不替代真实键鼠、Windows显示缩放、多屏、播放器识别或一小时稳定性验收。项目不附MV、原曲或原片音轨。
