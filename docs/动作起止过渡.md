# 动作起止过渡（2026-10-23～24，本地未发行）

本轮处理38组动作的开始、保持与结束。普通姿态先从站立进入，完成后恢复站立，再交给下一项；已有专用起坐、起身、落地、收板和下山过程继续由原时序负责。两张相差很大的身体立绘之间做淡化，不能算作这些身体过程。

## 普通动作与专用时序

`ActionBridgeState`位于同一Behavior内。普通动作切换登记“当前姿态→站立0→目标姿态”的路线，抱膝经过跪姿11，侧卧经过11、6；同一个站立身体不额外播放假动作。普通段约0.42秒，支撑跪/坐段约0.58秒，侧卧段约0.62秒，步态准备段约0.26秒。每段按真实经过时间推进，保持动作的`Time`在过渡期间冻结，原58%创建节点不会在拿板、屈膝或准备阶段提前触发。最终时长与路线以`src/ActionBridge.cs`为准。

身体中间画面来自新增的专用完整人物关键姿态。`SceneActionBridge.cs`将它们与原动作的精确端点配准，连续变形只连接相邻的实际关键画面；不用站立直接大幅扭成深蹲或侧卧。`ActorPoseWarp`在同一个身体网格中连续推进控制点，并生成单一透明轮廓；不会在桌面同时叠画两个人。二维光栅变形无法创造原图没有的背面、关节和遮挡关系，深姿态因而必须先有合适的原画，且仍需查看连续画面。

动作保持结束先回站，随后才抽取自主动作。明确操作只保留最后请求，重复当前动作不重启；过渡中再次操作从当前已显示画面接续。最终使用原基础站姿0的绘图、朝向、呼吸与地面根，避免另外一张“像站姿”的人物造成头身或脚位跳变。坐长椅/床沿继续使用当前座面与臀部锚点，不能按鞋底对齐椅面。

小跑、轻跃和转身继续使用已有专用收尾；Nurture继续使用完整下降/起身；秋千继续扶绳、坐下、减幅、起身；交互平板继续拿板、展开、点触和收板。通用过渡不能抢走这些专用过程的身体所有权。38个ID及动作页、自主创造、直接点击等入口差异见[检查表](动作过渡检查表.md)。

新图集共32个中间人物，不等于新建32个动作。保持姿态仍来自原基础图集或原专用序列。控制点中可见部位依照图像登记，被衣服或另一条肢体遮住的关节属于估计，不得据此声称测量了不可见骨骼。运行时读取已交付JSON与PNG，不要求安装Python、图像生成工具或Live2D。

原始生成提示词、参考和实际输出差异见[动作过渡素材制作记录](动作过渡素材制作记录.md)。图集按完整人物预载并登记，登山固定上身控制点只在载入时测量；播放中直接平移、镜像并覆盖连续腿部关节，不再每帧做整图连通域分析。下山的头、手臂与腿点一同镜像。专用时序的短交接跟随当前目标帧，不能冻结第一帧后突然追上已推进的动作。记忆原有的透明/虚化仍单独处理，不将近透明人物交给不透明身体网格。

过渡中改变请求时，从实际所处的身体段继续：早期取消贴地动作会回溯已经走过的原画，深段先收回到相邻支撑姿态，不以尚未到达的语义终姿选图。普通硬切场景/模式在身体过渡之前先校验所有专用时序上下文；同一登山、极光或接雪动作的重复选择不会排队重播。

EXE、manifest、上述PNG/JSON和原资源应配套使用。`build.ps1`检查新增运行文件，便携白名单明确列出它们；完整源码包保留设计文档、检查表、源码、测试与实际运行素材。

## 山径的进入与完整返回

登山仍使用原八个路线落点和连续双腿蒙皮。上/下山开始各增加0.48秒换重，山顶/山脚收脚各0.56秒；当前登山人物逐渐回正为精确站姿，准备段再从站姿进入当前登山身体。`StandingAmount`驱动连续不透明网格交接，不用淡化掩盖脚位、身高或躯干倾角差异。站稳阶段约0.20秒，再接看天或转身，正常每半步仍约0.6秒。

原正常时间轴已经有下山，本轮补的是普通结束入口。“结束观景”、点击Rin、选择新动作或创造/消息会请求沿山径返回：上山中先完成当前上行路线，山顶可提前结束8秒静观，下山中延续当前进度，抵达山脚并站稳后再执行最后请求。极光看天收回视线，接雪先保留完整收手。拖动、场景/模式改变、整理或山径支持失效仍优先硬取消，不强迫角色走完失效路线。

最终审图将山径转向也接入原`MotionExit`的回正与站稳，然后才开始prepare。首次实际呈现的站姿不能被一次较大的时钟步长吞掉，Journey的最后请求也不能在转身收尾阶段提前派发。坐姿新图的局部地面根与实际椅面不同，中间关键姿态按真实首末臀点渐进配准；不将完整坐姿在末帧突移到椅面。控制点检测受已登记头部区域限制并缓存，避免将转身时的手臂肤色当成脸。交互平板present/tap/stow分别交接，拖动保留抓取画面和同位控制点。

## 生命周期与存档

所有身体过程使用Behavior唯一时钟。暂停、隐藏、锁屏或全屏不推进普通动作；恢复延续原进度。未展开的创造/消息平板请求按原规则取消，恢复不补开。拖动保留用户抓住的实际画面，根位移立即跟随指针。场景/模式变更清除旧上下文的路线和请求，不能在新场景中重播。

成长、故事、来信、创造次数、两模式及各场景独立布局继续使用版本1存档。半段动作、过渡网格、待执行请求和图集缓存不进入存档；本轮不新增设置、提示、音效或外部依赖。

## 本地交付与检查范围

本轮目录为`dist/local/action-bridges/RinsLittleShelter`，附件放同级`release`，程序版本仍为1.0.2。此前`climb-continuity`、`motion-exit`及更早本地包和已公开v1.0.2保持原样；没有新Tag或GitHub上传。打包复用已构建EXE，说明为[本地交付说明](releases/action-bridges-local.md)。

默认构建包含`AllActionBridgeTests`、`ActorPoseWarpTests`、`ActionBridgeVisualTests`及原回归套件，分别检查38组动作逻辑、相邻姿态变形机制与连续生产绘图。最终结果见[验证记录](验证记录.md)，本说明不预写通过数。接触点、关节连接、透明边缘、比例与动作节奏还需查看当前资源的实际连续绘图；旧原型逻辑通过不能代替新图集通过。原生鼠标、真实系统DPI、多屏、播放器与一小时稳定性须分别实测。
