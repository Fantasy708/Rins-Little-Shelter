# 多场景素材制作记录

2026-10-12：使用内置 imagegen，以已有角色和场景图集保持画风一致。原片参考为官方短片约3:46的秋千、4:06的整理发饰；父亲生活装为灰色上衣、深色长裤，幼年Rin为深色长发、白色蝴蝶结和粉色服装，不采用父亲实验服立绘作为生活装。

参考：[官方影片](https://www.youtube.com/watch?v=fzQ6gRAEoy0)、[官网角色设定](https://www.sheltertheanimation.com/)。原片的树荫支架秋千按用户要求改为树枝固定长绳。

新增资源：world/scenes.png、world/swing-tree.png、rin/swing-life.png、rin/swing-loop.png、rin/family-memory.png。木座、绳索、临时粉色玩具袋由WPF绘制，不是图像编辑。所有原始生成图保留在本机。

登记脚本 scripts/register-scenes.py 只分析/登记资源裁切与锚点，不修改PNG。避免按假设等分裁切：父女图实际为1254×1254，坐下图为1122×1402，细化图为1536×1024。最初错误分母1280带入上一行鞋底碎片，已经修正。基础场景图集中家具行从550像素开始，避免带入上一行草地。

细化摆荡使用18张幅度较小、透明边缘完整的姿势，往返34个采样，4.6秒一周期（每姿势约135毫秒）；第一行夸张伸腿及右缘截断的6张未使用。完整坐下/起身图集有20张专用姿势。身体整体连接，髋部与手握位置逐帧登记；下肢以髋部为连续剪切起点，绳索和身体共用摆荡坐标，避免割裂与反复透明叠帧。

父女图集包含16格，其中屋内使用4格已成对绘制的整理发饰姿势，树下使用幼年Rin的4张坐姿和父亲的3张伸手/休息姿势。第3格生成了额外道具，不用于动画。不添加对白。记忆动画的自动绘图验证不能代替真实显示环境下的主观流畅度验收。
