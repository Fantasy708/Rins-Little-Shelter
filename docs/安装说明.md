# Windows 安装脚本

安装脚本用于 Windows 10（19041及以上）与 Windows 11 x64，无需管理员权限或开发工具。它从 Fantasy708/Rins-Little-Shelter 的 GitHub 正式发行下载便携包，按同发行的 SHA256 校验后安装。默认选择最新正式版，不选择预览版。

## 下载与安装

1. 在[正式发行页面](https://github.com/Fantasy708/Rins-Little-Shelter/releases/latest)下载 `RinsLittleShelter-Setup.zip`；`SHA256-Setup.txt`提供脚本包与支持脚本的校验值。
2. 完整解压脚本包，双击 `Install-RinsLittleShelter.cmd`。
3. 等待下载、校验和安装。成功后会创建桌面及开始菜单快捷方式，并启动Rin。

脚本包本身不含程序和素材，首次在线安装需要联网下载约250MB的便携包。GitHub连接失败时会显示原因并停止；也可使用下面的离线方式。已有同名且指向其他程序的快捷方式会保留，不会覆盖。

默认程序目录：

```text
%LOCALAPPDATA%\Programs\RinsLittleShelter
```

陪伴进度、布置、消息和设置继续使用原存档目录：

```text
%LOCALAPPDATA%\RinsLittleShelter
```

安装、升级和卸载都不清空这个存档目录，不新增开机启动、声音或提醒。建议先从托盘正常退出旧程序，再进行升级；脚本不会强行结束正在运行的Rin。

## 升级与卸载

再次运行安装入口即可下载最新正式版并升级。本脚本只接管自己登记的安装目录；如果目标已有其他文件而没有安装登记，会停止并提示选择独立目录。原有未登记的自定义文件会保留，同名冲突时停止。安装替换失败会回滚旧程序；临时备份无法清理时会显示其位置。

卸载时，先从托盘正常退出Rin，再运行安装目录内的 `Uninstall-RinsLittleShelter.cmd`，或开始菜单中的 `Uninstall Rin's Little Shelter`。卸载只删除登记且内容未修改的程序文件、仍属本安装的快捷方式，以及确实指向本安装的开机启动项。自己添加或修改过的文件和空文件夹会留下；如果仍有这些内容，程序目录也会留下。存档始终保留。卸载本身无需联网。

### 便携包和Setup包中的一键卸载（2026-10-25）

更新包位于`dist/local/v1.1.0-uninstall/release`，应用版本仍为v1.1.0；用户已授权更新同一GitHub发行，旧附件改名归档供回退。新版便携ZIP完整解压后，在EXE旁双击`Uninstall-RinsLittleShelter.cmd`，清理当前这份便携程序。文件夹移动或改名后，清单仍以当前位置为准；不会去删除原解压位置。只清理登记且未修改的程序文件，保留存档、用户文件及修改后的素材。没有有效登记、路径异常、发现目录链接或Rin尚在运行时会停止。

新版`RinsLittleShelter-Setup.zip`中也提供同名卸载CMD与PS1：双击可卸载默认安装目录的程序；自选安装位置请使用该程序目录里的卸载入口，或加`-InstallDirectory`指定。Setup脚本包自身保留，卸载入口不会根据文件夹名字猜测其他程序位置。旧便携包没有相对清单，不能只复制一个卸载CMD到旧目录直接删除；应使用完整修订便携包，安装版的旧登记仍可由新入口读取。

请保持CMD、`Uninstall-RinsLittleShelter.ps1`及引擎配套：便携/安装目录的引擎在`.setup/Install-RinsLittleShelter.ps1`，Setup包的引擎在根目录。推荐下载完整Setup ZIP；若手工使用散装脚本，需同时保留Install PS1与两份Uninstall支持文件，不能只下载新的Install PS1使用。脚本不更改系统执行策略。

## 自选目录和离线安装

在解压后的安装脚本目录打开PowerShell。以下命令只为这一次进程运行脚本，不修改系统执行策略。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-RinsLittleShelter.ps1 -InstallDirectory "D:\Apps\RinsLittleShelter"
```

提前下载同一正式发行的便携ZIP和 `SHA256.txt`，可以离线安装：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-RinsLittleShelter.ps1 -PackagePath ".\RinsLittleShelter-v1.1.0-win-x64.zip" -ChecksumPath ".\SHA256.txt"
```

便携包应保持正式附件文件名，不能只提供EXE。可以加 `-NoLaunch` 使安装后不立即启动，或 `-NoShortcuts` 不创建快捷方式。高级参数 `-Version v1.1.0`可指定正式版；`-DesktopDirectory`及`-StartMenuDirectory`可指定快捷方式目录，默认使用当前用户的Windows目录。

该脚本也支持直接卸载到指定安装目录：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-RinsLittleShelter.ps1 -Action Uninstall -InstallDirectory "D:\Apps\RinsLittleShelter"
```

## 源码和版本

安装引擎为 `scripts/Install-RinsLittleShelter.ps1`，卸载入口为 `scripts/Uninstall-RinsLittleShelter.cmd`与同名PS1；`scripts/portable-uninstall.ps1`在打包暂存目录生成相对卸载清单。`scripts/package-installer.ps1`生成完整脚本包、配套散装脚本和 `SHA256-Setup.txt`。脚本适配Windows PowerShell5.1和PowerShell7，PowerShell源文件使用UTF-8 BOM保证5.1中文可读。

安装入口于2026-10-25作为独立附件加入v1.1.0；之后用户授权将便携和Setup的卸载更新同步至同一发行。应用EXE与原应用Tag保持不变，脚本与文档另行提交main；新版完整源码包以发行说明中的脚本维护提交为准。更新ZIP使用新SHA256，不能沿用归档旧包的摘要。推荐下载完整Setup ZIP；散装脚本需要Install PS1及两份Uninstall支持文件配套。实际测试、上传状态和归档文件名见本包中的[验证记录](验证记录.md)和[发布状态](发布状态.md)。
