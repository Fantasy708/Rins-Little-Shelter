# Rin的平板消息界面设计

版本：`v0.3.0-preview.1`；整理日期：2026-10-13。本文件与[平板创造交互设计](平板创造交互设计.md)共同约束已实现的平板界面。参考核对、运行结果和待实测内容以[验证记录](验证记录.md)及[参考记录](平板参考核对.md)为准。本次按用户最新要求发布到现有私有GitHub仓库，旧版本保留。

## 两页共享一块平板

平板内提供“创造 / 消息”两页，共享同一外壳、拿起、握持、展开及收起流程。右键或托盘“查看平板消息”直接打开消息页，不另外弹出邮件窗口，不抢键盘焦点。

主动创造邀请切换到消息算作实际回应，转为手动会话，停止20秒未回应计时。切页清除临时创造预选；确认后的收回、点触和生成阶段不同时开放页面。阅读时Rin保持专用持板姿势与轻微呼吸，不能随机转身或走开。

## 消息状态

| 状态 | 屏幕表现 | 操作 |
| --- | --- | --- |
| 成长模式初始 | “No messages in 2593 days.”，可附简短中文说明 | 切回创造或关闭 |
| 一封未读信 | “父亲留给Rin的信”及稳定小圆点 | 用户主动点开正文 |
| 一封已读信 | 保留同一条记录，移除未读点 | 随时重新打开 |

**2593是固定故事数字**，不随电脑日期、安装时间或实际陪伴日增加，不要求用户等待2593天。

未读提示只在打开的平板内显示，不闪烁、不自动开信、不弹气泡、不发系统通知、不播放声音。列表不写“刚刚收到”，不把父亲预先留下的信表现成实时通信。

## 与父女记忆的连接

成长模式沿用第20个累计陪伴日开放父女记忆的规则。用户主动完整看过屋内或树下任一记忆后，开放同一封父亲来信；不要求两个片段都看，不要求重复观看。

“完整观看”的节点是父女片段结束、空场过渡完成、现在的Rin淡入恢复并进入观察。无需等最后观察结束。此节点单独产生正常完成事件，不能把通用取消流程当作看完。在节点之前提前结束、拖动、切换场景/模式或退出程序都不算完成；已经到达节点后再结束不撤回已开放的信。重复观看只更新同一条完成记录，不增加信件。

记忆暂停或暂时隐藏时不推进时间轴；如果正常恢复并到达完成节点可以开放来信。平板则在暂停或隐藏时关闭，恢复后不自动打开。记忆与来信的连接是桌面故事节奏适配，不声称原片中某个单独生活片段直接触发来信。

自由模式立即开放来信，也可随时重看记忆；自由模式阅读只保存自己的已读状态，不提前开放成长模式的信。两种模式分别保存完成、可读与已读记录。

## 阅读与文案

用户主动点开正文后才阅读。仅打开消息列表或排队打开不算已读；生产绘图实际呈现可读正文后，才保存当前模式的已读状态。关闭后可以重读，重新打开从第一页开始。页码只保存在当前会话中。

屏幕约280×200逻辑像素，正文14逻辑像素，分为三页。阅读时顶部保留标题、返回列表及关闭，底部使用明确的上一页/下一页与页码；返回列表后可切换创造页。分页由用户控制，不自动滚动，不缩小正文把全文塞满。

正式正文采用核对官方短片后的简短中文摘要，每页标注 **“原作来信内容摘要”**。摘要不署作父亲原话，不新增对白、剧情或父亲配音；无法核对的部分如实记录，不能把“正文待核对”作为成品。

正式摘要表达父亲从Rin健康、有活力的样子中获得力量、遗憾无法同行及希望她继续生活的心意。三页对应已在官方约4:59来信画面辨认的主题，不补写画面中未能确认的结尾：

1. 母亲去世后，Rin健康、有活力的样子，给了父亲继续向前的力量。
2. 父亲遗憾无法与Rin同行。他希望她能在留下的世界里生活，也相信她能够面对未来。
3. 他相信长大后的Rin，会读到并理解这封信；即使寂寞，也能继续走下去。

不添加回复、发送、删除、聊天生成、每日新信或签到任务。消息阅读不修改布置、天空、成长进度，也不消耗主动创造邀请次数。

## 原作参考与核对边界

主要参考：[Porter Robinson & Madeon官方短片](https://www.youtube.com/watch?v=fzQ6gRAEoy0)。本轮在约4:59来信画面直接辨认三段主题，据此制作以上中文摘要；没有把全文译文或无法确认的结尾署作原话。约0:42可以观察空消息界面，但小字无法逐字辨认，因此不能声称已核对原片该行的精确大小写和标点。

“No messages in 2593 days.”继续按用户明确确认的固定文案交付，2593不与本机时间绑定；这一要求与原片逐字核对的限度明确分开，参考截图不随交付包分发。

本项目仅对原作来信作简短中文摘要，不分发原片帧、原片音轨或全文译文。二手译文可以辅助理解，但不能替代原片核对，也不能将未经核对的信息写成父亲原话。前一轮设计整理未完成逐帧核对，不能继承为本轮已通过；本轮已观察与无法辨认的部分分别记入参考核对记录。

## 存档与流程边界

沿用版本1JSON的增量字段：`GrowthStory` / `FreeStory` 分别包含完成过的记忆ID、`FatherLetterUnlocked` 与 `FatherLetterRead`。只存在一封父亲来信；完成记忆使用已有场景ID `indoor` 或 `swingTree`，不会按日期生成新信。

旧存档缺少这些字段时取安全默认，不重置陪伴日、两种模式、场景布置或位置。成长旧档即使达到20日，也需重新完整观看一次记忆；不从访问场景、文件时间或记忆播放中间状态推断已看完。自由模式可读来自自由规则，读取不写成长记录。保存沿用原子写入与备份恢复。

`LifeSequence` 在现在的Rin恢复后发出独立完成事件，并带入记忆开始时的场景/模式身份；过期事件不能更新另一个模式。平板控制器的“正文已呈现”回调检查会话代次、当前页、模式与场景，取消后的迟到绘图不标记已读。

页面、页码、预选和展开状态只在内存中存在。拖动、整理、场景或模式切换、记忆、隐藏、暂停、锁屏、全屏隐藏和完全穿透均优先关闭平板、清除命中；恢复后不自动重开。已保存的可读/已读状态保留，平板外透明空白仍可操作下面的窗口。

## 验收边界

检查固定2593空态、两模式独立、完整/提前退出/重复记忆、正常完成与取消区分、正文呈现后已读、重启与备份恢复，以及消息不改变布置或创造计数。文字、按钮和命中使用生产绘图检查100%/150%/200%缩放。

实际完成项由最终[验证记录](验证记录.md)登记。未进行的原片逐帧细节、真实桌面输入、Windows显示缩放切换及一小时稳定性不能写成通过。
