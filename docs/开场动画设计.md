# Rin’s Little Shelter 启动开场设计

版本：v0.3.1，2026-10-14。设计基准见[design.md](../design.md)，实际验收范围见[验证记录](验证记录.md)。

## 体验与素材

开场表达“这里有一个正在成长的小世界”。在现有480×340逻辑像素的小世界窗口中，Rin从安静的星光里苏醒，观察草甸，用平板让一粒种子开花，再回到用户自己的场景。默认静音、不覆盖整屏、不抢焦点，用户可以随时跳过。

画风沿用项目现有半Q版Rin与插画资源。天空、柔光、慢速数字光片、种子与嫩芽由WPF绘制；草甸复用`assets/world/nurture-grass.png`及现有透明轮廓，云与花复用`assets/world/objects.png`。Rin使用`assets/rin/poses.png`中的闭眼、站立、看天和微笑，以及`nurture-life.png`前六张俯身姿势、`tablet-life.png`专用持板/点触/收起姿势。没有新增角色图、音乐或原片素材。

首版不另做独立挥手图集；以朝向用户的微笑接回日常，保持现有身体比例、服装和绘图方式。正常姿势序列不逐帧透明叠加；首次出现的淡入和阶段边界过渡服务于开场叙事。

## 时序

完整开场约14.4秒，实际时间推进，不等待用户回应。

| 阶段 | 时间 | 画面 |
| --- | --- | --- |
| 星光 | 0–2秒 | 短暂深蓝背景与少量蓝绿慢速光点，没有快速闪烁 |
| 世界渐生 | 2–5秒 | 天空、云、细草与小花逐渐出现，只有轻微缩放和柔光 |
| Rin苏醒 | 5–8.6秒 | 闭眼角色渐现，睁眼、观察、俯身轻触草地，再起身拿起平板 |
| 创造一朵花 | 8.6–11.4秒 | 持板点触，几何光片、种子落地、发芽开花，随后收起平板 |
| 进入桌面 | 11.4–14.4秒 | 显示标题和中英文副标题，微小拉远，Rin微笑后交接当前保存场景 |

后续简版约3.1秒，呈现柔和天空、标题与Rin的回应，随后恢复用户当前场景。完整及简版都不会将演示草甸替换成保存场景的布置。

## 操作与保存

设置中的“启动开场”提供三种策略：

- **首次完整，之后简短**：默认；旧存档没有已看字段时同样首次完整。
- **每次完整播放**：每次正常启动完整播放。
- **直接进入桌面**：关闭自动开场。

画面右下角与托盘均提供“跳过开场”。设置页“重看开场”主动播放完整版本。完成或用户主动结束后，版本1存档保存全局`HasSeenStartup`；切换成长/自由模式不重复首看，也不改变各自故事状态。半段动画的阶段、临时种子或花不持久化。

开场只呈现临时世界，不解锁真实景物、不调用创造事件、不改变保存位置与隐藏状态，不消耗每日创造邀请，也不生成父亲来信。日常行为与音频采集在开场期间等待，交接后按现有设置恢复。

## 中断与技术边界

隐藏、暂停、锁屏、休眠、全屏、整理、场景/模式切换、完全穿透及用户主动互动优先结束开场。清除覆盖层与旧命中，恢复后不自动重开。既有诊断启动默认跳过开场，可用`--startup full|brief|skip|auto`显式选择。

模块位于`src/Animation`：控制器负责短时间轴，Canvas绘图负责呈现，粒子只保留24个固定缓慢轨迹，窗口部分负责交接和命中。沿用现有`CompositionTarget.Rendering`帧钟，无新增长期定时器；结束后由原单一`Behavior`接管Rin。

745项自动检查已覆盖播放策略与时长、旧档与备份、五场景/两模式交接、各阶段中断、三档导出缩放、透明圆角及命中、完整姿势合成。自动WPF绘图和直接调用窗口接口不能代替原生Windows输入验收；最终EXE短运行的数据以验证记录为准。本版本一小时稳定性、真实100%／150%／200%系统缩放、多屏及桌面操作观感仍待人工实测。
